# 시스템 기획 내용

## 플레이 방식
캐릭터를 간단하게 조작해 점프와 슬라이딩을 하며 장애물들을 피하고 도착지점까지 달리는 게임

## 스테이지 구성
쉬움, 중간, 어려움 세 가지 난이도로 나눌 예정

## 캐릭터 모델

## UI 구성

### 타이틀 화면:
- 상단 게임 타이틀
- 중앙 시작 버튼(스테이지 선택 화면으로 이동)
- 끝내기 버튼(게임종료)

### 스테이지 선택 화면
- 왼쪽, 가운데, 오른쪽으로 화면을 3분할해 쉬움, 중간, 어려움 난이도 선택 버튼 구성

### 게임 화면:
- 상단 캐릭터 체력바
- 좌측 상단 점수 표시
- 좌측 하단 점프 버튼(Space/화살표위/W)
- 우측 하단 슬라이딩 버튼(Ctrl/화살표아래/S)

### 게임 오버 화면:
- 상단 게임 오버 메시지(완주 or 실패)와 점수 표시
- 중앙 재도전 버튼(해당 스테이지 재시작)
- 하단 타이틀 화면으로 버튼(타이틀 화면으로 이동)
